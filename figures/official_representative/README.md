# Official representative trajectory outputs

These files are representative outputs from official Run 01 of each configuration.

They are provided for qualitative reproducibility and inspection only.

The four experimental groups were manually teleoperated and did not follow identical trajectories or sensor sequences. These representative images therefore must not be used for causal baseline-to-YOLO comparisons.

Primary quantitative conclusions are based on the 10-run aggregate statistics available under `metrics/official_aggregates/` and in the complete Zenodo archive.

# Official representative map files

This directory contains map artifacts that were explicitly preserved in the official Zenodo archive for Run 01.

For Run 01, archived PGM/YAML map pairs are available for RTAB-Map and RTAB-Map + YOLOv8n.

No Cartographer Run 01 PGM/YAML pair is added here because an equivalent pair was not present in the official reproducibility archive. Older repository map files should not be interpreted as matched quantitative map-quality evidence.

Occupancy-map appearance is used only qualitatively in the manuscript.

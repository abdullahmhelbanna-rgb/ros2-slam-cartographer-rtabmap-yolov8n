# Metrics

## Official revised results

The authoritative lightweight aggregate results are located under:

`metrics/official_aggregates/`

They contain 10-run results for:

- Cartographer
- Cartographer + YOLOv8n
- RTAB-Map
- RTAB-Map + YOLOv8n

Each configuration contains 10 analyzed runs.

The complete run-level data and evaluation outputs are archived at:

https://doi.org/10.5281/zenodo.22878936

## Legacy material

The older configuration directories directly under `metrics/` were retained from the initial repository release and should not be used in place of `official_aggregates/` for the revised manuscript.
